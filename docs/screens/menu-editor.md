# メニュー作成画面

## 目的

複数種目の組み合わせを名前付きで保存し、次回以降の Workout 開始を短縮する。

## 表示

- メニュー名の入力欄
- 登録済み種目の一覧
- 種目の選択状態
- 「種目を追加」ボタン
- キャンセル / 保存のナビゲーション操作

## 作成手順

1. Home の「メニューを作成」をタップする。
2. メニュー名を入力する。
3. 種目を複数選択する。
4. 必要なら「種目を追加」で新しい種目を作る。
5. 「保存」をタップする。

## 入力ルール

- メニュー名は前後の空白を除去する。
- 空のメニュー名、種目なしのメニューは保存しない。
- 種目追加時は、同一部位・同一記録方法の同名種目を重複登録しない。
- 作成途中にキャンセルしても、既存メニューと種目マスタを変更しない。

## 保存と利用

メニューは UserDefaults に JSON で保存し、各種目の UUID の順序を維持する。Home の保存済みメニューから「開始」を選ぶと、保存された種目構成を新しい Workout に展開する。

## 削除

メニュー一覧で左スワイプ、または長押しメニューから削除する。確認ダイアログを表示し、削除しても種目マスタや過去履歴は削除しない。
