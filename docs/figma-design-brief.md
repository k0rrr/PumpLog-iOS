# PumpLog Figmaデザイン指示書

## 1. デザインの目的

筋トレ中に片手・短時間で記録でき、前回の成長や鍛えた部位を直感的に確認できるiOSアプリをデザインする。

デザインの優先順位は次の順とする。

1. 記録の速さ
2. 現在のトレーニング状態の分かりやすさ
3. 過去の成長の見やすさ
4. 鍛えた部位の達成感

## 2. デザイン対象

### 必須画面

- 記録タブ（トレーニング未開始）
- 記録タブ（入力中）
- 種目追加シート
- 種目ごとの入力タブ
- テンプレート選択シート
- テンプレート作成画面
- トレーニング完了後の初期状態
- 履歴一覧、履歴詳細・編集
- 成長グラフ
- 身体部位マップ
- 種目管理

### 将来画面

- 人体アバター（前面）
- 人体アバター（背面）
- 部位詳細（負荷量・対象種目・期間）

## 3. 全体ナビゲーション

画面下部にiOS標準の5タブを配置する。

| タブ | アイコン例 | 役割 |
|---|---|---|
| 記録 | plus.circle | トレーニングの入力・完了 |
| 履歴 | clock | 過去の記録、検索、編集 |
| 成長 | chart.xyaxis.line | 重量・回数・総負荷量の推移 |
| 身体 | figure.arms.open | 鍛えた部位の可視化 |
| 種目 | list.bullet | 種目とテンプレートの管理 |

## 4. ビジュアル方針

### キーワード

```text
シンプル / 力強い / 清潔 / 集中 / 達成感
```

### カラー

| 用途 | 推奨 |
|---|---|
| Primary | 青または濃いブルー。主要アクションと選択状態 |
| Success | 緑。保存成功、自己ベスト |
| Muscle load | 薄い赤 → 濃い赤。負荷の強さ |
| Warning | オレンジ。入力不足、注意 |
| Destructive | 赤。削除操作 |
| Background | iOS systemGroupedBackground |
| Card | iOS secondarySystemGroupedBackground |
| Text | Label / SecondaryLabel相当 |

システムカラーを優先し、ライトモードとダークモードの両方を作成する。色だけで状態を伝えず、アイコン、ラベル、数値も併記する。

### 文字

- iOS標準フォント（SF Pro相当）
- 画面タイトル：Large Title
- セクション見出し：Headline
- 種目名：BodyまたはHeadline
- 補足情報：Footnote、Caption
- 重量・回数・タイマー：Monospaced Digit
- 最小文字サイズは11pt以上

### 角丸・余白

- カード角丸：12〜16pt
- ボタン角丸：10〜12pt
- 画面左右余白：16pt
- セクション間隔：16〜24pt
- タップ領域：44pt以上

## 5. 記録画面の詳細

### 5.1 未開始状態

表示内容：

- ナビゲーションタイトル「PumpLog」
- 日付選択（年月日のみ）
- 「種目を追加」ボタン
- 「テンプレートを使う」ボタン
- 空状態メッセージ「種目を追加してください」

空状態では、初めて使うユーザーでも次に押すボタンが分かるよう、テンプレート利用と種目追加を明確な2つのアクションとして表示する。

### 5.2 入力中状態

上から次の順で配置する。

1. 日付
2. 「種目ごとに入力」セクション
3. 種目タブ
4. セット追加フォーム
5. セット一覧
6. 休憩タイマー
7. 種目メモ
8. トレーニング完了

#### 種目タブ

- 横スクロール可能なタブ
- 「種目1」「ベンチプレス」のように番号と名前を表示
- 選択中はPrimaryカラーの背景と白文字
- 未選択は薄いグレー背景
- 種目数をセクション右側に表示
- 下部に「タブを切り替えると、種目ごとのセットを入力できます」と表示

#### セット追加フォーム

- 重量入力：プレースホルダー「重量 (kg)」
- 回数入力：プレースホルダー「回数」
- 右側に主要ボタン「追加」
- セット追加後は入力値を空にする
- セット追加後はキーボードを閉じる
- 入力エラーはフィールド直下に短い説明を表示

#### セット一覧

- 「Set 1」「Set 2」のように番号表示
- 重量、kg、回数、回を横並びで表示
- 種別は「ウォームアップ」「通常」のセグメント
- 右上に三点メニュー（複製、削除）
- 下部に「最後と同じセットを追加」
- 完了チェックマークは使用しない

#### 休憩タイマー

- 休憩時間Picker：1分、1分30秒、2分、3分、5分
- ボタン「休憩を開始」
- 実行中は画面下部に固定バナー
- 残り時間を大きな数字で表示
- 「+30秒」「終了」を表示

### 5.3 完了後状態

完了成功後は、セット入力フォーム、セット一覧、種目タブ、種目メモ、タイマーを表示しない。

未開始状態へ戻し、保存成功または自己ベスト更新の通知だけを表示する。

## 6. 種目追加シート

- タイトル「種目を追加」
- 種目名と部位を一覧表示
- 右上に「新しい種目」
- 左上に「閉じる」
- 既に追加済みの種目にはチェックマークを表示
- 種目を選択した場合だけ親画面へ追加して閉じる
- 何も選択せず閉じた場合は、既存の種目数を変更しない

## 7. テンプレート画面

### 7.1 テンプレート選択

タイトルは「テンプレートを選択」とする。

画面上部に説明文を表示する。

```text
よく使う種目の組み合わせを一度に追加できます。
```

テンプレートカードには次を表示する。

- テンプレートアイコン
- テンプレート名（例：胸・肩の日）
- 種目数
- 種目名一覧
- タップ可能であることが分かるアクセント

### 7.2 テンプレート作成

- タイトル「テンプレートを作成」
- テンプレート名入力
- 種目の複数選択
- 選択中はチェック付きアクセント表示
- 保存ボタンは名前と1種目以上の選択がある場合のみ有効
- 補足文「よく使うメニューを保存すると、記録画面からまとめて開始できます」

## 8. 履歴画面

### 一覧

- 日付ごとにグループ化
- 日付、種目名、セット概要、総負荷量を表示
- 検索バー：種目名またはメモ
- フィルター：部位、過去7日、30日、90日、全期間
- カレンダー表示への導線

### 詳細・編集

- 日付編集
- セットの重量・回数・種別編集
- メモ編集
- 保存、削除
- 削除は確認ダイアログを表示

## 9. 成長画面

- 種目選択Picker
- 期間選択
- サマリーカード：最高重量、最高回数、総負荷量、自己ベスト
- 折れ線グラフ：重量、回数、総負荷量
- データがない場合は説明付き空状態
- グラフの各点をタップすると日付と値を表示

## 10. 身体部位画面

### 現行版（2Dマップ）

- 人体の前面・背面を表示
- 記録がない部位はグレー
- 負荷がある部位は赤系グラデーション
- 凡例を表示（未記録、低負荷、中負荷、高負荷）
- 部位タップで部位名、負荷量、対象種目を表示

### 将来版（アバター）

- 2Dと同じ部位IDを利用する
- 前面・背面を切り替え可能
- 部位をタップすると詳細シートを表示
- 3Dモデルへ変更しても集計ロジックは変更しない
- 赤色の強度は期間内の相対負荷に応じて変化させる

## 11. 種目管理画面

- 種目一覧
- 部位、器具、詳細部位の補足表示
- 種目の追加、編集、削除、並べ替え
- 「テンプレート（メニュー）」セクション
- テンプレート名と含まれる種目名を表示
- 説明文「よく使う種目の組み合わせを保存すると、記録画面からまとめて開始できます」

## 13. プロトタイプフロー

### 初回記録

```text
記録（未開始）
  → 種目を追加
  → 種目選択
  → セット入力
  → 追加
  → キーボード閉じる
  → 休憩開始
  → 完了
  → 記録（未開始）へ戻る
```

### テンプレート記録

```text
記録（未開始）
  → テンプレートを使う
  → テンプレート選択
  → 複数種目が追加される
  → 種目タブ切替
  → 各種目のセット入力
  → 完了
```

### キャンセル確認

```text
テンプレート記録中
  → 種目を追加
  → 何も選択せず閉じる
  → 既存の種目数・セット内容を維持
```

## 15. Figmaへ渡す短縮プロンプト

```text
iPhone向けの日本語筋トレ記録アプリ「PumpLog」をデザインしてください。
記録の速さを最優先し、iOS標準UIに馴染むシンプルで力強いデザインにしてください。
画面は記録、履歴、成長、身体、種目の5タブ構成です。
記録画面では、複数種目を横スクロールのタブで切り替え、各種目のセット入力フォームを表示します。
テンプレート選択画面にはテンプレート名、種目数、種目名一覧、用途説明を表示してください。
テンプレート利用中に種目追加画面を閉じても、既存種目が減らない操作フローにしてください。
重量・回数入力後はキーボードを閉じ、トレーニング完了後は入力フォームとセット一覧を空の初期状態に戻します。
身体画面では、負荷が高い筋肉部位ほど赤く表示し、将来2Dから3Dアバターへ拡張できる構成にしてください。
ライトモードとダークモード、空状態、エラー状態、完了状態、コンポーネントVariantsを作成してください。
```
